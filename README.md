# SkillNexus Data Science Internship - Week 4 Capstone Project

## Project Overview
This repository contains the complete deliverables for **Week 4 (Data Visualization & Capstone Project)** of the SkillNexus Data Analyst Program. It covers end-to-end data processing, exploratory analysis, linear regression sales forecasting, and interactive stakeholder dashboards.
